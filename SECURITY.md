# Security Policy

## Supported Versions

FTA is under active development and has not yet been released. There are no
supported versions; that will change once it goes to production.

## Reporting a Vulnerability

Report a suspected vulnerability by opening an
[issue on this repository](https://github.com/bcgov/nr-fta/issues).

**Do not include exploit details, credentials, or personal information in a
public issue.** If the finding is sensitive, open an issue saying only that you
have a security report and asking for a private channel, and a maintainer will
follow up.
